# 星塔爬塔：音符状态空间

## 0. 模型设置

本文规定音符的完整输入、真状态与可见状态、动作、包级奖励、阶段配额、库存、协奏、事件、货架、计分和快照续跑。与潜能联合运行时，[潜能状态空间](StateSpace.md)继续定义路线、潜能、金币、强化及事件类型生成；本文扩展音符库存与相关结果，不另维护潜能规则副本。

当前模型：`note_joint_working_v2`，配置schema为`stella_note_generation_v1`。下文记录当前最佳可执行解释，并以选定的随机程序直接生成新对局；实测依据、竞争假说和精确参数见[音符状态空间观察报告](NoteStateSpace_Observation_Targets.md)。规则目录与已恢复的客户端确定转移直接使用，不进入概率验证清单。统计支持与唯一服务端实现、精确常数的确定分开记录。

### 0.2 游戏状态、玩家状态和机制配置

游戏真状态含库存、隐藏配额、惊喜失败数、上次首领结果及RNG。玩家状态含当前公开库存、菜单／货架、历史和隐藏状态的相容路径或后验；策略不能读取尚未公开的配额位置或未来随机结果。早期程序、配额概率、池内权重等机制配置随模型版本固定，不与某一局隐藏状态混为一体。

生成器可以保存内部诊断真值；策略输入使用公开观察，后续需要续局分析时从完整快照克隆，不把隐藏真值混进策略输入。

## 2. 计分、奖励与目标

### 2.1 音符分与协奏分

音符构筑分：

\[
V_{note}(s)=15\sum_{i=90011}^{90023}\min(n_i,99).
\]

对每个主秘纹关联的协奏组g，从所有音符需求均满足的行中选最高等级a_g；没有满足行则未激活：

\[
a_g(\mathbf n)=\max\{l:\forall i,\ n_i\ge Need(g,l,i)\},
\qquad
V_{concerto}(s)=\sum_{d\in main}\sum_{g\in groups(d)}Score(g,a_g).
\]

求和按主秘纹持有项及其组处理；不能把三张主秘纹需求的并集当成一条协奏。154个正常组各有5级，另有特殊记录9001；特殊行按目录与秘纹绑定使用，不自动分给全部队伍。326行需要两种音符、445行需要三种。常见门槛10／25／40／55／70或15／30／45／60／75，实际值逐行查表。

A_local由库存重算；A_server是实机服务器下发的激活ID集合，分开保存。实机终局采用返回的A_server；模拟局按本规则计算并标明来源。

### 2.2 任务奖励

潜能总有效等级继续为Z=6+Σmin(t_i,l_i)，不把游戏构筑分换算为潜能等级。生成器沿用当前价值模型的非核心口径，输出potential_effective=Z−6、note_build=V_note、concerto_build=V_concerto三个分项；每步同时输出各分项delta，终局输出完整分项结果。核心固定6另加即可，不进入原始普通目标或结构范围。

任务可以另行选择终局收益 `R = potential_effective + λ × concerto_level_sum`，其中 λ 由任务指定。在最终商店结束后，按每件主秘纹绑定的每个协奏组取终局已达到的最高等级，未激活记0，再相加得到 `concerto_level_sum`。裸音符库存和游戏显示的协奏构筑分分别保存；中途激活、升级不重复计入终局等级。

独立生成器默认随机选择合法动作，保留原始分项、终局音符库存及秘纹配置，可据此重算各组等级。兑换可能降低当前音符分，购买消耗金币；不因某一步分数下降剔除合法动作。

### 3.3 可见状态与后验

observe仅提供当前已公开的库存及完整性、协奏、金币、潜能页、事件菜单、货架和合法动作。未公开的配额位置、包顺序、失败真值、下一首领结果和RNG不进入策略输入。

完整变化仍可能不唯一：单条+9可为一个升级包，也可为三个普通包；同类包会合并。先联合整场包数与完整向量枚举相容分解，再按选定核更新后验，不把弹窗条目数当作机会数。设b_t(k)为公开隐藏状态后验：

\[
b_{t+1}(k')\propto\sum_k b_t(k)P(k',o\mid k,a_t,I).
\]

缺少包级先后时对隐藏顺序求和；相同公开结果的后台路径合并。实机缺失只限制依赖该字段的推导，不遮蔽其他独立清晰字段，不把拟合路径改成实测真值。

### 3.4 快照与变化量

进塔／续局Bag.Items是赋值，交互响应Data.Infos逐条累加：

\[
n_{Tid}\leftarrow Qty\quad（快照）, \qquad
n_{Tid}\leftarrow n_{Tid}+Qty\quad（增量）.
\]

库存10收到+5后为15，收到−5后为5。快照、战斗、事件、购买分别处理；不从所有floor=1差分统一减3来猜开局归属。

## 4. 路线、动作与顺序

共享路线及核心／普通奖励顺序使用[潜能规格§2](StateSpace.md#2-完整楼层与执行顺序)。音符挂到同一BATTLE指令，在战斗结算时发放，随后处理核心、普通奖励和追加NPC。非首领为1／3／4／7／8／10／11／14／15／17／18层，首领为6／13／20层。

| 动作／自动转移 | 音符侧结果 |
|---|---|
| BATTLE | 自动执行§5，更新库存及隐藏计数，再回共享路线 |
| SELECT／REROLL | 使用共享潜能转移，不改音符计数／配额 |
| SELECT_EVENT(index) | 按当前零基显示索引找具体选项；支付／获得及潜能创建属于同一次结果 |
| CLOSE_EVENT | 免费结束，仍保留已见事件去重 |
| BUY(Sid) | 扣实际价格、标记已购；音符立即入库，饮料进入奖励页，处理后返回原货架 |
| ENHANCE | 共享强化转移，不改音符过程 |
| RESTOCK | 扣100、次数减1，整架按E6替换；库存及战斗计数保留 |
| LEAVE | 离店，最终店离开后END |
| MODIFY_NOTES(Δ) | 满足构筑入口时执行§8.2；独立于正常爬塔终局 |

动作使用当前页面、金币和许可；未处理的潜能页不能跨过去继续买下一件。随机音符类型不是玩家动作，兑换不允许自行选择损失最小的扣取分配。

## 5. 当前可执行的随机程序

### 5.1 类别池

D为掉落池经40101元素条件处理后的有效集合；由塔、难度、主控元素和固定满研究条件独立确定，不根据某局缺少的音符反推。C为三个主秘纹全部协奏组所有等级需求ID的去重并集与D的交集。当前按静态C抽类，不因协奏已激活、当前等级需求已满足或整组满级而删除类型；真正满级后的特殊处理仍为观察目标H07。

当前程序：每局初始化时，为C内每类独立抽整数w_i~UniformInteger(100,150)，为补集每类抽w_i~UniformInteger(100,200)，固定到本局结束。C与D\C均非空时，先以4/5进入C、1/5进入补集，再按该集合内w_i归一化抽类；开局／战斗／随机事件共用同一组权重。主池／补集结构及局内持续类别效应获实测支持；具体整数范围与跨来源共享仍为工作假说。直接池内等权、每区间重抽及来源分别持有权重保留为明确竞争程序。

主池为空或覆盖全部D时直接退回全D，仍按本局type_weights归一化；C为空时各权重来自[100,200]，C=D时来自[100,150]。已满协奏不缩池。within_pool_mode=uniform时，以上所有候选池内改为等权。

战斗每个基础包抽类一次；随机事件每枚一次。商店音符种类使用全D等权，不套用战斗／事件80%主池分支。指定事件用指定种类，辅助供给查表。

总库中已知D的87局，战斗与事件联合主池1955/2465=79.310%；当前4/5与其相容。每局持久权重相对池内等权的物理局95%比较支持持续效应，但共享权重与来源分开尚未区分。按需要该类的主秘纹张数直接正／反加权均明显较差，需求重复出现不增加该类权重；具体比较见观察报告S06、S10、S12及H07／H08。

### 5.2 开局与早期

辅助供给发放后，开局额外3枚作为一个独立基础包处理：按§5.1抽类，并参与§5.5惊喜机会。该包只发一次，随后再处理第1层战斗基础包和额外包。开局是否参与惊喜是当前工作假说，可配置；观测统计不据此强行选定首层baseline分支。

早期非首领1／3／4层各有1个基础包，额外包分别独立以0.15／0.15／0.025触发；触发时再增加1个基础包。当前程序允许同局出现两次及三次。这是选定工作程序，现有完整分支尚未排除“早期至多一次名额”的竞争解释。第3层14/84、第4层5/89及81局配对支持这两个位置的差异；独立性、首层概率和精确常数继续留H01。

实机首层在原始变化向量上联合枚举开局包和战斗包，开局包本身也允许惊喜升级；不先固定减3再分解首战。首层18枚可由开局与首战基础包各升级一次产生，不能据此强制增加一个早期额外包。所有首层区间一起退出早期率拟合，保留它们的完整相容分支用于连续历史分析。

### 5.3 中段与末段配额

初始化时为中段预抽Q_mid~Bernoulli(2/3)。若为1，从7／8／10／11层按权重[2,2,4,1]选一个位置，其他位置不加包；若为0四场均不加包。执行中段时每场仍有1个基础包，命中所选位置时再加1包。

初始化时同时为末段在14／15／17／18层按权重[4,4,3,2]逐次加权无放回选两个不同位置。第一次按原权重抽，删除后第二次按剩余权重归一化；执行末段时四场恰有两场各增加1包。这里采用逐次加权抽签，不等同于“每对位置概率正比权重乘积”。

阶段名额只决定增加基础包，不直接消耗惊喜次数。当前总库69个完整中段中45个有一个名额、24个没有；63个完整末段全部恰2，支持阶段内负依赖。名额率和位置权重仍是工作参数。名额加位置分布可以等价改写为按剩余条件概率逐场抽签、命中后关闭的hazard，现有四场结果不能辨认服务端采用哪种代码实现；当前生成器固定使用上述预抽程序，不按实测模式表抽轨迹。

### 5.4 首领幸运

每场首领基础2包，根据boss_previous抽本次幸运，成功再加3包，故总包数2或5：

| 上次结果 | 当前工作概率 |
|---|---:|
| 尚无首领 | 54/88 |
| 成功 | 61/109 |
| 失败 | 1 |

本次结果写回boss_previous。当前首次和成功后分别采用54/88、61/109的经验常数；它们是否需要不同概率仍未分清。失败后53/53次成功，精确95%区间为[.93277,1]，支持前次结果依赖；失败后1是选定工作端点，尚非已证明严格常数。

额外3包分别抽类，9枚可以分散多类；不写成必给单类9枚。当前5包都参与惊喜；双方优化惊喜参数后，5次机会对仅4次／3次的物理局95%比较均获支持，见观察报告S14。后台首领结果不等于实读LuckyLevel或橙色标签。

### 5.5 包级惊喜

每个参与惊喜的基础包抽类得到t_j，基础3枚；封顶前执行：

~~~text
if surprise_used == 4:
    z = 0
else:
    p = min(1, 0.2 + 0.2 * surprise_failures)
    z = Bernoulli(p)
    if z:
        surprise_used += 1
        surprise_failures = 0
    else:
        surprise_failures += 1
notes[t_j] += 3 + 6*z
~~~

连续失败数跨房型、阶段和商店保存，成功归零。跨战持久、成功清零和进店不清零获实测支持。当前程序中事件、购买、辅助供给不消耗惊喜机会，音符事件也不清零失败数；跨音符事件保留与重置仍未分清。第4次触发后，后续包不再推进有效失败数。整场为：

\[
\Delta\mathbf n=\sum_{j=1}^{b}(3+6z_j)e_{t_j},
\qquad r'=r+\sum_jz_j\le4.
\]

同类包合并显示，生成时保留机会顺序。首领(12,9,12)共33枚可由5包、3包升级构成；人工(9,9,3,3,3)共27枚可由5包、2包升级构成。样本最大值不是生成上限；5包且剩余4次惊喜时理论可得39枚，属于工作核推导。

当前总库89局、871场连续前缀支持失败递增、成功清零及跨战／店持久。20%初率＋每次失败20%增量与数据相容，仍作为简洁工作核；自由加法核与几何递增核尚未分开，精确线性、最高档严格100%及开局包是否参与继续列H05／H06。

固定14战且4次惊喜用完时，仅计一次开局3枚与战斗的净增可写为78+3X+9Y；X为非首领额外包次数，Y为首领幸运次数。两者受阶段／前次结果影响，不作为独立二项变量；辅助供给、事件、兑换、购买另算。

### 6.2 随机扣取

当前按枚无放回：在全部13维实际库存中，每次以n_i/Σn抽一枚、将对应n_i减1，再按剩余库存重算，重复5或10次。塔外辅助供给也参与。总库存N、扣取k时损失向量d服从：

\[
P(\mathbf d\mid\mathbf n,k)=
\frac{\prod_i{n_i\choose d_i}}{{N\choose k}},
\quad\sum_id_i=k,\quad0\le d_i\le n_i.
\]

默认配置以辅助秘纹214009／214024的Phase=8供给28枚，再处理开局奖励，满足默认数据的初始支付条件。自定义配置仍按真实库存执行：库存不足5／10时相应动作不可执行，不补造音符、不记负库存。共享潜能抽象中的“始终可支付”在音符过程通过足额配置与真实合法动作实现。

库存枚数加权已获支持；无放回是当前最佳工作程序。27次显示足额扣款中，无放回相对固定初始权重的logL差−.531、物理局95%[−1.665,.473]，相对带容量限制的整批重抽也未分清；这些近邻算法继续列H09，不让策略选择损失分配。未显示的塔外库存按已观察子池条件化，不补零。

### 6.3 共享E6商店

数量和折扣采用[潜能规格§8](StateSpace.md#8-商店与货架)的E6程序，保留全部8件后补充音符身份：小包5枚原价90，大包15枚原价400，饮料原价200。默认每个音符商品在全D等权抽一种类，整包同类；shop_preferred_probability=null，不把战斗／事件的80%主需求池关系直接移到货架。类型与大小的精确关系仍为工作假说。

当前最佳来源解释是商店独立从全D抽类：已知D的431架／83局中，全D等权相对战斗／事件80%主池核提高211.025 logL，物理局95%[157.698,267.893]。这支持两种来源使用不同类别机制，尚未证明全D内精确均匀或大小与身份完全独立。

首次补货的暴伤burst大包关联在合并数据中存在，但明确可见补货计数的子集尚未区分具体1.5权重候选。H11保留的可执行竞争程序为：条件于音符商品身份集合，在首次补货架中分配大包标签时，burst权重1.5、其他种类权重1。当前默认仍按全D抽取，未把该条件候选嵌入共享E6。

E6每架为额外主饮Y和大包B从十张票不放回抽两张，Y/B四格概率(1,5,2,7)/15，大包边际4/5。G=2−b+X，M=b+Y，b=int(shopOrdinal==1)，首店补货仍有偏置；X=min(2,Binomial(4,.65−.05Y))，小包数6−X−Y−B。票只在同架Y/B间共享。

全部8件均匀选4件折扣，再在折扣中选D=min(2,Binomial(3,p_D))件半价，其余八折；第2／3店初始p_D=3/4，其余初始和全部补货7/10。不能先删音符商品再只给饮料分折扣。

实际价为Discount>0 ? Discount : Price，按Sid买并记已购；显示排序不代表后台抽取顺序。补货不重发供给，不重置任何战斗计数。

## 8. 终止、修改与快照续跑

### 8.1 终止与复现

第20层首领后仍有普通潜能与最终店；最终店离开后END。保存全13维终局库存、激活协奏、各分项得分、原始预设、模型配置与轨迹种子。

快照包含§3完整状态、已打开的页／菜单／货架、公开历史或足够信念，以及全部RNG当前位置。相同快照和相同动作复现相同后续；只存初始seed不足以中途恢复。续局不重发供给、不重抽已公开货架、不重置配额或失败数。

同根多动作比较从各自克隆开始，使用约定的独立续局seed或公共随机流并保存协议；不能把前一动作推进后的状态直接作为下一动作起点。

### 8.2 构筑修改

修改独立于正常爬塔终止。入口：非限时试用、未锁定、构筑分≥5800、修改状态0或1，消耗35013×1；状态2已改音符、3不可修改。

提交新减旧的Δ，可调换1–15枚：

\[
\sum_i\max(\Delta_i,0)=\sum_i\max(-\Delta_i,0)=k,
\quad0<k\le15,\quad0\le n_i+\Delta_i\le99.
\]

成功采用返回构筑与激活ID。包含修改的任务在输入声明奖励和终止位置；默认爬塔终局不自动增加一次未声明的改音符优化。
