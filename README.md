## Cadenza II

纯潜能模型于 2026 年 11 月 21 日定稿。在 4,960 组等权预设的 1,269,760 对独立整塔评测中，Cadenza II 比初版 Cadenza 提高 **0.01854 ± 0.00197 分**（配对标准误）。
